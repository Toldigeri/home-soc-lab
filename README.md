# Home SOC Lab

A self-built home lab for practicing SOC analyst skills, simulating
real-world attack scenarios and documenting the detection and
investigation process.

## What's inside
- **SIEM:** Splunk Enterprise (Ubuntu Server)
- **Attacker machine:** Kali Linux
- **Target:** Windows 10 (Sysmon) and Ubuntu Server
- **Simulated attacks:** SSH brute force, network reconnaissance (more to come)
- **Documentation:** incident reports mapped to MITRE ATT&CK

## Structure
- `incidents/` – individual incident write-ups
- `detections/` – custom detection rules
- `screenshots/` – supporting evidence

## Why this project
Built to gain hands-on SOC analyst experience: detection, triage,
investigation and reporting, using an isolated home lab environment.
